
# Proyecto_Compilador

## Instalar la libreria lark para construccion del arbol sintactico
Utilicen el siguiente comando --> pip install lark

## Generador de Interfaces Gráficas o HTML/CSS desde un DSL
Un lenguaje ultra simplificado para describir layouts visuales que se compile a código HTML/CSS limpio o a un script de Tkinter/CustomTkinter en Python.

## Tokenizador
- Definición de los tokens a utilizar: palabras claves, identificadores y símbolos.
- Funcion lista para el parser --> Entrega todas los tokens listos para el armado del arbol.

## Parser (AST) --> Especificacion de gramatica en GRAMATICA.md
- Conversion de los tokens a árbol.
- Manejo de errores sintácticos.
- Función lista para empezar con el backend.

- Utilizar el siguiente comando -- pip install customtkinter pillow
